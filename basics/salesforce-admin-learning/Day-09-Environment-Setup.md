# Day 9: Salesforce Environment Setup

## Objective

Set up the Salesforce learning environment by creating a Trailhead account and a Salesforce Developer Org.

This environment will be used throughout the Salesforce Admin learning journey.

---

## What is Trailhead?

Trailhead is Salesforce's official learning platform.

It provides:

- Learning Modules
- Trails
- Badges
- Superbadges
- Certification Preparation

Trailhead helps learners gain Salesforce knowledge through structured and hands-on learning.

---

## What is a Salesforce Developer Org?

A Salesforce Developer Org is a free Salesforce environment used for learning, development, and testing.

It allows users to:

- Create Objects
- Create Fields
- Configure Security
- Build Automations
- Practice Salesforce Administration

without affecting real business data.

---

## Trailhead vs Developer Org

| Trailhead | Developer Org |
|------------|--------------|
| Learning Platform | Practice Environment |
| Contains Modules | Contains Salesforce Instance |
| Earn Badges | Build Applications |
| Learning Focused | Configuration Focused |

---

## Salesforce Setup

The Setup Menu is the administration center of Salesforce.

Administrators use Setup to configure:

- Objects
- Fields
- Users
- Security
- Reports
- Automations

Almost all Salesforce configuration activities begin in Setup.

---

## Object Manager

Object Manager is a Salesforce administration tool used to manage:

- Standard Objects
- Custom Objects
- Fields
- Relationships
- Page Layouts

It is one of the most frequently used sections by Salesforce Administrators.

---

---

## Key Takeaways

- Trailhead is Salesforce's official learning platform.
- A Developer Org is a free Salesforce practice environment.
- Setup is the main administration area.
- Object Manager is used to manage objects and fields.
- Trailhead and Developer Org work together for learning and practice.
