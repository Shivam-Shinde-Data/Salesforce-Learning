# Day 14: Record Creation & Data Management

## Introduction

Records contain actual business data stored inside Salesforce Objects.

After creating objects and fields, administrators and users create records to use the application.

Example:

A Student record stores information about one student.

---

## What is a Record?

A Record is a single stored entry inside an object.

Records are similar to rows in an Excel sheet or database table.

---

## Object vs Field vs Record

| Component | Meaning |
|---|---|
| Object | Database Table |
| Field | Column |
| Record | Row/Data |

---

## CRUD Operations

CRUD represents the four major record operations:

| Operation | Meaning |
|---|---|
| Create | Add new record |
| Read | View existing record |
| Update | Modify record |
| Delete | Remove record |

CRUD operations are fundamental in Salesforce.

---

## Creating Student Records

Inside the Students Tab:

1. Click New.
2. Enter student details.
3. Click Save or Save & New.

Example:

| Field | Value |
|---|---|
| Student Name | Rahul Sharma |
| Roll Number | 101 |
| Department | Computer Science |
| Email | rahul101@gmail.com |

---

## List Views

List Views display multiple records together in table format.

They help users:

- Search records
- Filter records
- Manage data efficiently

---

## Record Management

Users can:

- Create records
- Edit records
- Search records
- Delete records

This process is known as Record Management.

---

## Key Takeaways

- Records contain actual business data.
- Objects store records.
- Fields store individual pieces of information.
- CRUD operations are core Salesforce operations.
- List Views help manage records efficiently.
