# Day 23: Schema Builder

## Introduction

Schema Builder is a visual tool in Salesforce used to view and manage objects, fields, and relationships.

It helps admins understand Salesforce architecture visually.

---

# What is Schema Builder?

Schema Builder is a visual interface used to display Salesforce objects and relationships.

It works like a database diagram for Salesforce applications.

---

# Features of Schema Builder

Schema Builder helps users:

- View objects
- View fields
- View relationships
- Understand data models
- Create fields visually

---

# Components Visible in Schema Builder

| Component | Visible |
|---|---|
| Objects | Yes |
| Fields | Yes |
| Relationships | Yes |
| Standard Objects | Yes |
| Custom Objects | Yes |

---

# Example

```text
Student__c
   ↓
Course__c
```

The relationship between objects appears visually inside Schema Builder.

---

# Steps to Open Schema Builder

1. Open Setup.
2. Search Schema Builder.
3. Open Schema Builder.
4. Select Custom Objects.
5. Observe objects and relationships.

---

# Object Information

Each object box displays:

- Object Name
- Fields
- Field Types

---

# Relationship Lines

Relationship lines represent connections between objects.

Example:

```text
Student → Course
```

---

# Object Manager vs Schema Builder

| Tool | Purpose |
|---|---|
| Object Manager | Detailed object configuration |
| Schema Builder | Visual architecture view |

---

# Why Companies Use Schema Builder

Companies use Schema Builder for:

- System planning
- Understanding relationships
- Documentation
- Data modeling
- Architecture visualization

---

# Key Takeaways

- Schema Builder provides visual architecture view.
- It displays objects, fields, and relationships.
- It helps admins understand Salesforce systems easily.
- Relationship lines show object connections.
- Schema Builder supports data modeling.
