# Day 13: Page Layouts & UI Customization

## Introduction

Page Layouts control how fields, buttons, sections, and related lists appear on Salesforce record pages.

They help administrators improve user experience and organize information properly.

---

## What is a Page Layout?

A Page Layout is a Salesforce feature used to control the visual arrangement of fields and components on a record page.

Page Layouts improve readability and usability.

---

## Why Page Layouts Are Important

Page Layouts help:

- Organize fields
- Improve navigation
- Improve user experience
- Group related information together

Without Page Layouts, records can become cluttered and difficult to use.

---

## What Page Layouts Control

Page Layouts can control:

- Field placement
- Field order
- Sections
- Buttons
- Related Lists
- Required fields (layout-level)

---

## What Page Layouts Do NOT Control

Page Layouts do not control:

- Security
- Record access
- Field permissions

These are managed using Profiles, Permission Sets, and Field-Level Security.

---

## Sections in Page Layouts

Sections are used to group related fields together.

Examples:

### Academic Information

- Roll Number
- Department
- Admission Date

### Contact Information

- Email
- Phone

---

## Steps to Customize Page Layout

1. Open Setup.
2. Open Object Manager.
3. Select Student Object.
4. Open Page Layouts.
5. Open Student Layout.
6. Add Sections.
7. Drag fields into sections.
8. Save layout.

---

## Key Takeaways

- Page Layouts control UI appearance.
- Sections improve organization.
- Layouts improve user experience.
- Objects store data, while layouts organize data visually.
- Salesforce uses drag-and-drop UI customization.
