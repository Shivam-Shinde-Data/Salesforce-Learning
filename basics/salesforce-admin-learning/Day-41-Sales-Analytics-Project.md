# Day 41 – Sales Analytics Project

## Project: Sales Analytics Dashboard

Built a Salesforce Sales Analytics project to demonstrate practical reporting, dashboard, and data analysis skills.

## 1. Sales Object

Created a custom **Sales** object with the following fields:

- Sale Number – Auto Number
- Sales Amount – Currency
- Sale Date – Date
- Category – Picklist
- Region – Picklist
- Salesperson – Text
- Status – Picklist
- Quantity – Number

## 2. Sample Data

Created **10 Sales records** with different categories, regions, salespersons, statuses, dates, quantities, and sales amounts.

Sample categories:
- Clothing
- Electronics
- Furniture
- Grocery
- Healthcare

Sample statuses:
- Completed
- Pending
- Cancelled

## 3. Sales Analytics Reports

Created reports to analyze sales performance from different business perspectives.

### Sales by Category
- Grouped records by Category
- Calculated Sum of Sales Amount
- Added a bar chart to compare category-wise revenue

### Sales by Region
- Grouped records by Region
- Calculated Sum of Sales Amount
- Used the report for regional performance analysis

### Sales by Status
- Grouped records by Status
- Calculated Sum of Sales Amount
- Used the report to compare Completed, Pending, and Cancelled sales

### Total Sales
- Created a report-based KPI showing the overall Sales Amount

## 4. Sales Analytics Dashboard

Created a **Sales Analytics Dashboard** containing:

- Total Sales KPI
- Sales Amount by Category
- Sales Amount by Region
- Sales by Status

Added dashboard filters for interactive analysis and arranged the components into a clean business-friendly layout.

## 5. Business Insights

The dashboard can be used to identify:

- Highest-performing sales categories
- Best-performing regions
- Overall sales revenue
- Completed vs Pending vs Cancelled sales
- Salesperson performance
- Areas requiring business attention

## 6. Admin Concepts Practiced

This project provided practical experience with:

- Custom Objects
- Custom Fields
- Picklist Fields
- Auto Number Fields
- Currency and Number Fields
- Creating Records
- Reports
- Report Grouping
- Summary Calculations
- Report Charts
- Dashboards
- Dashboard Components
- Dashboard Filters
- Business-oriented Data Analysis

## 7. Project Outcome

Successfully built a complete **Sales Analytics solution in Salesforce** starting from data modeling and sample data creation to reports, charts, dashboard visualization, and business analysis.

This project demonstrates how a Salesforce Administrator can transform operational data into meaningful reports and dashboards that support business decision-making.
